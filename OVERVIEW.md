Jumps to the next agent that is waiting for your answer, in any workspace on the daemon. A question with choices, a plan to approve, a tool permission and a mode switch all count: anything Paseo shows as "needs input".

Press Cmd+Shift+U on macOS or Ctrl+Shift+U on Windows and Linux. Each press opens the agent that has been waiting longest after the one the plugin opened last, switching workspace when needed, and wraps around after the last. When you answer an agent it leaves the queue, so the next press skips it. The same action is in the Command Center as "Next waiting question" and as a "Next question" row in the sidebar, which shows how many agents are waiting. The sidebar row and Command Center item work on mobile; the keyboard shortcut needs a hardware keyboard in the desktop app or a browser.

Paseo does not tell plugins which agent tab has focus, so "next" is relative to the agent this plugin last opened, not the tab you are looking at. After a plugin reload the cycle restarts at the agent that has waited longest. The plugin reads the agent list of the daemon it is installed on and sends nothing anywhere else. Agent tabs only: terminals are not included. Finished and failed agents are not included. If the plugin is installed on several daemons, only one of them handles the shortcut in a given window.
